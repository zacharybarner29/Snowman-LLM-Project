# LLM Project
I took the code from my Snowman Project and had Codex build a front end for playing the game.

##  Key features and extensions
- **How to play:**
  - User tries to guess a word by inputting a letter, receiving a hint, or guessing the whole word
  - When the user gets six letters wrong, a snowman melts into a puddle
- **Extesnions:**
  - Difficulty and language settings
  - An image of a snowman that melts when letters are incorrect
  - Sidebar of incorrect letters
  - A win/loose screen that shows the player's score or the correct word

## Challenges I Ran Into
When I attempted to open the front end generated by Codex, it said the file did not exist. This was because, by organizing my Codex-generated file into a separate folder, Codex lost access to it due to privacy restrictions. I moved this file to my Documents folder so Codex can access the front end and everything else in the file.

## What I'd Improve With More Time
- Add more extensions to the front end
- Change the visual appearance of the front end to make it look less AI-generated
- Try using different LLMs to compare their different outcomes
